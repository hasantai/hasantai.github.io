# Hasan Tai portfolio

- `index.html` home. `experience.html`, `certifications.html`, `awards.html` are top-level pages.
- `projects/index.html` lists all projects. Each project has its own page in `projects/`.
- `assets/style.css` is the shared design. `assets/img/` holds images.

## Add a project
1. Copy `projects/_template.html` to `projects/my-project.html` and fill it in.
2. Put images in `assets/img/` (.webp or .jpg, under 300 KB each).
3. Copy one `<a class="card">` block into `projects/index.html` (and into `index.html` if it is a featured project) and point it at the new page.

## Add a certification
Copy one `<li>` in `certifications.html` and edit the name, issuer, date, and Credly link.
