Pedestrian Automatic Emergency Braking prototype

ECE 471, Data Communications, Fall 2026

An ESP32-CAM streams live video over its own Wi-Fi access point to a laptop. A Python application runs a pretrained YOLOv8 model restricted to people, then checks whether each person’s feet sit inside a trapezoidal driving-path polygon and whether the bounding box is tall enough to count as close. The highest alert in each frame passes through a debounce filter that is quick to raise and slow to clear, then appears as a color-coded border with a beep and a CSV log entry.

Checking only the feet against the path, instead of the whole box, cut false BRAKE alerts for bystanders. The system warns but does not brake, and box height is only a rough distance proxy.

Sequential tail light controller

ECE 273, Digital Systems, with Hussien Hassan

A Moore state machine modeled on 1966 Ford Thunderbird turn signals. Eight states stored in three D flip-flops drive six lights through idle, left, right, and hazard sequences that run to completion once triggered. Next-state and output equations were minimized in Logic Friday, written in Verilog in Quartus Prime, checked in simulation, then run on an FPGA board with a clock divider slowing the 50 MHz clock to a visible rate. Hardware behavior matched simulation.

  • Quartus Prime
  • FPGA
  • State machines

UART-controlled temperature test bench

Personal project, STM32F103, in progress

A Python (pyserial) script sends commands over UART to a Blue Pill board that switches a relay and an RGB LED and reads a DS18B20 temperature sensor. Every reply is an ACK or NACK with timeout handling, and automated pass/fail checks log to CSV. The build is moving one stage at a time, with each part tested alone before it joins the full firmware.

Photos, test logs, and a GitHub repository will go here as each stage is finished.
